## Notes for web display

### How to route the customer
- **Wants flip-up convenience for touring** (open face at stops, easy over glasses, big road miles) → **GT1 Expedition**
- **Wants a peak + does mostly road with some off-road** → **X1 Alpha** (the road-primary all-rounder)
- **Rides off-road a lot / wants the lightest / tighter budget** → **Krios Pro** (also available in cheaper closeout colours)

### Certification clarification
- **GT1 Expedition** and **Krios Pro** state **ECE 22.06 / DOT** on their product pages — quote with confidence.
- **X1 Alpha** lists only **"ECE/DOT certified"** — the ECE version (22.05 vs 22.06) is **not printed** on the KLIM page. Motolegends discuss it as a 22.06-era helmet (mandatory visor lock). **Confirm the exact standard in-store — do not state 22.06 as fact for the X1.**

### Weight
- KLIM publishes weight for the X1 Alpha (1550 g L) and Krios Pro (1450 g L). KLIM does **not** publish a weight for the **GT1 Expedition** — the ~1661 g (M) figure is third-party (Champion Helmets). Present it as an independent measurement, not KLIM-official.
- Order lightest → heaviest: **Krios Pro (~1350 g M) < X1 Alpha (~1500 g M) < GT1 Expedition (~1661 g M)**. Modulars are heavier by nature.

### Price gotcha (important)
- Quote from the **product pages**: GT1 $999.99 · X1 Alpha $899.99 · Krios Pro $724.99.
- KLIM's **cross-sell tiles show stale prices** (e.g. X1 shown as $699.99, Krios as $599.99 in some "also bought" panels). Do **not** quote those — use the product-page price or confirm in-store.

### Chin strap systems (a real differentiator)
- **GT1 Expedition:** micrometric ratchet (quick-release) — typical of touring/modular helmets
- **X1 Alpha:** titanium D-ring — KLIM *dropped* the Fidlock for this
- **Krios Pro:** Fidlock® magnetic — some riders specifically prefer it; it's only on the Krios now

### KOROYD® construction difference
- **X1 Alpha** and **GT1 Expedition** sandwich the KOROYD® between two EPS layers → cooler and quieter, and (X1) KLIM claim 42% more impact absorption than EPS-only.
- **Krios Pro** uses **mostly KOROYD®** — the older approach, which is lighter but (per Motolegends) transmits more shell noise to the ears. This is the main reason the X1 is quieter.

### "Confirm" cells
Where a cell says **Confirm**, the KLIM product page does not state that spec (e.g. GT1 size-L weight, Krios optical class / shell count / exhaust vent count). Staff should verify in-store rather than infer — consistent with the CE/spec rules in the project brief.
